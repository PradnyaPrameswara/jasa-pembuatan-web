# Premium Web Agency Design Skill

This project specific skill establishes the identity and visual constraints for the agency website.

## Identity & Tone

The interface must consistently feel:

- **Premium:** High execution quality, no shortcuts.
- **Editorial:** Content-first, relying on strong typography and whitespace over heavy decoration.
- **Calm & Restrained:** Avoiding visual noise, flashing elements, or demanding animations.
- **Technical & Precise:** Alignment, spacing, and structural logic must be mathematically sound.
- **Modern:** Contemporary layouts without chasing fleeting trends.

## Core Rules

1. **High-Quality Typography:** Typography is the primary visual element. Use deliberate tracking (tighter for display, looser for small UI), controlled leading, and clear hierarchy.
2. **Controlled Translucent Materials:** Glass (`backdrop-filter`) is NOT a default aesthetic. It is a functional tool used only to establish spatial relationships (e.g., floating navbars overlapping content, sheets over dimmed backgrounds).
3. **Strong Spatial Hierarchy:** Grouping, padding, and layout must clarify relationships instantly. Use opaque surfaces (near-white/cool-neutral) for content areas and deep charcoal for high-contrast sections.

## What to Explicitly Reject

When designing or implementing components in this repository, **DO NOT** use:

- **Excessive Glass:** Applying blur to ordinary cards or backgrounds without a reason.
- **Generic SaaS Cards:** Identical pricing-style cards used for content.
- **Bento Grids by Default:** Only use masonry/bento if the content genuinely demands it.
- **Cyberpunk / Neon:** Glowing borders, neon text, or hacker aesthetics.
- **Large Gradient Blobs:** "Web3 style" blurry colored orbs in the background.
- **Random Pills:** Overusing rounded-full shapes for unrelated UI elements.
- **Fake Dashboards:** Placeholder mockups of non-existent software products.
- **Unnecessary Decorative Animation:** Heavy scroll choreography, bouncing elements, or page transition delays. Motion must be purposeful and structural.
