# Premium Web Agency Website

A premium web development agency website focused on technical precision, accessible design, and fluid interactions.

## Tech Stack

- **Framework**: [Astro](https://astro.build/) (v5)
- **UI Islands**: React (v19)
- **Styling**: Tailwind CSS (v4)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)

## Getting Started

Make sure you have Node.js and `pnpm` installed.

```bash
# 1. Install dependencies
pnpm install

# 2. Start the development server (runs on localhost:4321)
pnpm dev
```

## Validation & Build

Ensure all code passes validation before committing.

```bash
# Check code formatting (ESLint & Prettier)
pnpm lint

# Check TypeScript types
pnpm typecheck

# Check Astro compilation & types
pnpm run check

# Build for production
pnpm build
```
